# Автопостинг Feeriya в Telegram

- `posts.json` — тексты, картинки и время публикации (UTC+3). Редактируйте прямо тут.
- `posted.json` — номера уже опубликованных постов (обновляется ботом).
- Бот запускается каждый час (Actions → «Автопостинг в Telegram»), можно запустить вручную.
- Секрет `TG_BOT_TOKEN` — токен бота. Необязательная переменная `TG_CHAT_ID` (по умолчанию `@feeriya`).
